# BetterReview

BetterReview is an independent terminal code-review application for GitHub and GitLab.

The project is under active development. Its first release will provide file-by-file review, single-line and multi-line comments, suggestions, resumable sessions, reviewed-file progress, and the `COMMENT`, `APPROVE`, and `REQUEST_CHANGES` outcomes.

BetterReview uses the authenticated `gh` and `glab` command-line tools and renders provider patches with the real `git-delta` executable. Neovim integration will remain an optional terminal launcher.
